The user also reported the generic error after running the connection command themselves. Safe error reporting now exposes the failed operation and known native status without raw credential-bearing diagnostics. The macOS cause remains unresolved; the next step is user-side login Keychain reauthentication and one marker check after that change. No Gmail token was involved and there is no plaintext fallback. See the [diagnosis evidence](../validation/PHASE_04_GMAIL.md#native-failure-diagnosis-and-error-reporting).

The file parses as a Desktop client with the required fields; values were not displayed, the file is restricted to owner read/write, and a repository-local exclusion keeps it out of Git while preserving the user's existing ignore-file edits. The proposed starting scope remains recent seven-day inbox mail, 20 messages per batch, bodies only; no real account query has been issued. Google project/API/test-user readiness is not proved by the JSON format check. Tokens/passwords should not be pasted into chat.
