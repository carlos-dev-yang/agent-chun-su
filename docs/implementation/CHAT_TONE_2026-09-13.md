# CHAT-TONE-01 — 별도 말투 지침과 채팅 설정

2026-09-13 사용자는 말투를 기본 지침과 완전히 분리하고, `/말투` 메뉴에서
옵션을 고르거나 커스텀 지침을 직접 입력하여 저장하도록 요청했다. 한 데이터 홈의
채팅에 공통 적용되는 Markdown 파일을 사용하며 DB에 설정을 추가하지 않는다.

## 적용 범위

- Telegram과 로컬 자연어 채팅에서 같은 기계식 설정 대화를 사용한다.
- `/말투` 또는 `/말투 옵션`으로 메뉴를 열고 번호를 선택한다. 정중한 존댓말,
  편한 존댓말, 친근한 반말, 간결한 업무형과 커스텀 입력을 제공한다.
- 커스텀 옵션을 선택한 뒤 보낸 지침은 AI가 바꾸지 않고 저장한다.
- 현재 설정 조회, 기본 말투로 초기화, 설정 대화 취소를 제공한다.
- 옵션 선택 상태는 각 수신기/로컬 대화의 메모리에만 두고, 선택된 말투만
  데이터 홈의 `instructions/chat-tone.md`에 원자적으로 저장한다.
- `/reset`과 재시작은 선택 중인 메뉴를 닫지만 저장된 말투는 유지한다.
- 기존 고정 관리 명령과 답변 취소 기능을 유지한다. 설정 메뉴는 AI가 실행되지
  않는 상황에서도 사용할 수 있다.

## 자동 주입

접수 AI의 매 생성 단계 직전에 파일을 새로 읽고, 기본 대화 Skill·실행 권한과
구분된 응답 스타일 지침으로 프롬프트에 포함한다. 이전 대화 이력에 설정을
끼워 넣거나 모델이 파일을 알아서 읽는 방식에 의존하지 않는다.

말투는 채팅의 표현 방식에 적용한다. 별도 업무 실행기·보고서·평가자의 지침이나
권한은 바꾸지 않는다. 설정 변경 후 새로 시작하는 생성부터 적용하며 이미 생성 중인
응답에는 이전 지침이 사용될 수 있다. 고정 시스템 안내는 기존 기계식 문구를 사용한다.

파일 없음이나 초기화로 저장한 빈 파일은 기본 말투다. 저장은 private 파일 규칙과 설정된 입력/파일 크기 한도를
따르고, 전체 프롬프트 한도도 계속 적용한다. 파일 읽기 오류는 설정 복구 안내로
보고한다. 설정 대화와 사용자 지정 말투는 일반 대화 이력이나 추적 기록에 복제하지 않는다.

## 완료 증거

상태: 구현·로컬 검증·Telegram 재시작 및 연결 확인 완료. 관련 패키지 컴파일·정적 검사와 독립 리뷰를 완료했다.
분리된 데이터 홈에서 AI 없이 메뉴·프리셋·커스텀·취소·초기화를 확인했고, 실제 AI
답변과 새 프로세스의 상태 조회 답변에 커스텀 지침이 적용됐다. 읽기 권한 오류의
기계식 안내와 초기화 복구도 확인했다. 새 테스트 코드는 만들지 않았다.
